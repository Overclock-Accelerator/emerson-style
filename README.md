# Emerson Style

Ahmed's named premium writing voice: a polished executive-consulting register built on extracted PwC / Strategy& thought-leadership patterns, with anti-AI gates enforced before delivery.

Two skills live here:

| Skill | Path | What it's for |
|---|---|---|
| **emerson-style** | [`emerson-style/SKILL.md`](emerson-style/SKILL.md) | The voice itself — profile, gates, calibration passages. Plain markdown; works as a style guide for any writer or model. |
| **update-emerson-style** | [`update-emerson-style/SKILL.md`](update-emerson-style/SKILL.md) | For teammates who want a fresh version: checks the installed copy against the repo, installs the latest, and reports what changed. |

## What the voice does

- Drafts copy in a measured, boardroom register: claim → evidence → implication, with qualified verdict sentences landing the point.
- Runs five gates before delivery: rhythm (including a connective-tissue check), AI-tell vocabulary, structural AI-tells (device density, argument shape, persona poses), a Do/Don't checklist, and Vale linting.
- Bans the habits that make prose read as AI: stacked colons, repeated rhetorical questions, bare pithy verdicts, advice-register shifts, hip in-group framing, knowing asides, negative-reveal openers, in-line justification, and closers that announce their own insight.
