# Emerson Style

Ahmed's named premium writing voice: a polished executive-consulting register built on extracted PwC / Strategy& thought-leadership patterns, with anti-AI gates enforced before delivery.

The style lives in [`SKILL.md`](SKILL.md) — a Hermes Agent skill, but the profile, gates, and calibration passages are plain markdown and work as a style guide for any writer or model.

## What it does

- Drafts copy in a measured, boardroom register: claim → evidence → implication, short verdict sentences landing the point.
- Runs five gates before delivery: rhythm, AI-tell vocabulary, structural AI-tells (device density, argument shape), Do/Don't checklist, and Vale linting.
- Bans the structural habits that make prose read as AI: stacked colons, repeated rhetorical questions, negative-reveal openers, in-line justification ("which is exactly why"), not-X-but-Y pivots in any phrasing, and closers that announce their own insight.
